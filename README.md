# 派派的快乐小鸡乐园

这是一个面向儿童的鼠标操控启蒙游戏套装：把单击、连续点击、按住拖动、路径控制和精准放置，拆成六步由易到难的游戏练习。应用完全静态、可离线运行；电脑上双击 `打开游戏.command`（Windows 可继续使用 `打开游戏.bat`），iPad 安装请双击 `启动iPad安装.command` 并按照 [iPad安装说明.md](iPad安装说明.md) 操作。

English documentation: [README_EN.md](README_EN.md). 游戏设置中可切换“中文 / English”；语言选择保存在当前设备中。英文界面包含菜单、玩法提示和设置，现有语音素材仍为中文，并在英文界面标明“Chinese voice prompts”。

## 鼠标能力路线

| 步骤 | 游戏 | 主要训练 | 玩法反馈 |
| --- | --- | --- | --- |
| 1 | 快乐小鸡下蛋 | 单击定位、手眼协调 | 点击位置决定母鸡落点，鸡蛋依次孵化 |
| 2 | 泥坑跳跃 | 目标选择、连续点击 | 先选泥坑，再保持点击节奏 |
| 3 | 鸡舍分类 | 抓取、拖动、松开 | 把鸡蛋或小鸡拖进正确颜色的鸡舍 |
| 4 | 小鸡迷宫 | 按住拖动、路径控制 | 沿通道连续画出种子路线，不碰墙 |
| 5 | 快乐拼图 | 精准拖放、空间定位 | 拖近正确位置后自动吸附，支持4/9/16片 |
| 6 | 我的贴纸册 | 自由拖放、迁移运用 | 用已掌握的操作自由布置8个场景 |

六步并不是年龄或能力测验，也不对训练效果作医学或教育效果承诺；它们只是把常见鼠标动作放进孩子愿意重复尝试的游戏情境。游戏同时支持鼠标和触屏；空格键可辅助下蛋，Esc 或左上角按钮返回。游戏音效、中文提示音和两类重置操作都在右上角设置中。旧版的循环电子背景音乐已经彻底移除。

## 宣传片

一分钟产品演示位于 [宣传素材/派派的快乐小鸡乐园-鼠标训练宣传片-1080p.mp4](宣传素材/派派的快乐小鸡乐园-鼠标训练宣传片-1080p.mp4)。配套封面、能力定位和可复现的录制合成脚本见 [宣传素材/展示说明.md](宣传素材/展示说明.md)。视频不含实时字幕或字幕轨。

## 本地检查

```sh
node tests/logic.test.js
node tests/static-audit.mjs
python3 -m http.server 4173
node tests/browser-smoke.mjs http://127.0.0.1:4173/index.html
```

浏览器检查会覆盖13个关键场景/视口、鼠标、触屏、四个拖拽游戏、空格、反复进出、50枚蛋、45枚贴纸、16片拼图、存档恢复和断网冷启动。

## 中文语音素材

中文提示语已使用 Qwen3-TTS 1.7B 的 Serena 普通话女声音色在本机离线生成，并加入自然、轻快而克制的儿童游戏引导语气。游戏内只加载生成后的 WAV 文件。以后需要重新生成时，可在 Apple Silicon Mac 上运行：

```sh
uv run --python 3.12 --with mlx-audio python tools/generate_qwen_voice.py
```

模型许可和来源见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
